# UPI Transaction Analysis

## Project Overview
This project analyses UPI transaction data to understand transaction performance, payment trends, and potential fraud indicators. MySQL was used to structure and analyse transaction data, while Power BI was used to present key metrics and insights through visualisations.

## Tools & Technologies
- **MySQL:** Data querying, aggregation, and transaction analysis
- **Power BI:** Dashboard development and data visualisation
- **Excel:** Data handling and preliminary analysis, where applicable

## Key Contributions
- Analysed UPI transaction records to evaluate transaction success rates, transaction types, and payment trends.
- Structured and queried relational database tables covering customers, merchants, transactions, devices, and fraud alerts.
- Developed a Power BI dashboard to visualise key performance indicators and communicate analytical findings.

## Project Objectives
- Understand UPI transaction patterns and performance.
- Examine transaction failures and potential fraud indicators.
- Present findings in a clear, accessible format to support data-driven decision-making.

## Repository Contents
This repository contains the SQL scripts, analysis documentation, and dashboard or report files associated with the project, as uploaded.
